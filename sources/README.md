# Fastlåste regelkilder

Det autoritative [manifest og de otte PDF-filer](../openspec/changes/build-teamgym-team-manager/reference/source-manifest.json) følger med i dette repo. De duplikeres ikke her; ændringens reference-mappe er kildesamlingen.

`npm run verify:sources` kontrollerer bytes og SHA-256 uden netværk eller parent-mappe. Bygningen stopper ved afvigelse. Ingen kilde opdateres automatisk. Katalogimport og beregningspakker er endnu ikke implementeret.
