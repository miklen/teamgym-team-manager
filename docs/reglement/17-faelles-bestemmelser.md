## Struktur og regler

| ID / sted           | Indhold                                                                                                                                                                                                                                                                                 |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FK-01 / §1-3, s. 1  | GymDanmarks regler er underlagt DIF's bestemmelser. Sportsteknik og konkurrenceform findes i aktivitetens reglement. Officielt DM kræver DIF-godkendelse.                                                                                                                               |
| FK-02 / §4, s. 1    | Foreningsmedlemskab i GymDanmark og gyldig licens. Gymnast kan ikke repræsentere to foreninger i samme disciplin; flere hold kan tillades i aktivitetens reglement. Medlemskab af en GymDanmark-klub i tre måneder før danske mesterskaber/officielle konkurrencer. Se konflikt med TR. |
| FK-03 / §5, s. 1    | Forbundsmesterskab med én deltager kan gennemføres, men ingen vinder/medalje; med mindst to kan der kåres vinder. Regionalt kan én deltager kåres og få medalje.                                                                                                                        |
| FK-04 / §6, s. 2    | Medaljer til 1/2/3; aktivitet fastlægger rækkefølge og reserver/trænere. Ved delt førsteplads fx to guld, ingen sølv, én bronze.                                                                                                                                                        |
| FK-05 / §7-8, s. 2  | Synlig GymDanmark-afsender. TV-aftale kræver forbundsledelsens godkendelse; internetstreaming aktivitetens godkendelse og må ikke stride mod TV-aftale; økonomiske retningslinjer gælder.                                                                                               |
| FK-06 / §9-10, s. 2 | Flag anbefales ved udenlandsk deltagelse; passende beklædning skal beskrives af aktiviteten og tage hensyn til sikkerhed, udtryk, reklamer og ensartethed. Henvisning til internationale beklædningsregler.                                                                             |
