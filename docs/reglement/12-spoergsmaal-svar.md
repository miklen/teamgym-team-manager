## Struktur og alle afklaringsemner

S. 1-3 rytme, s. 4 trampet. Engelske punktnumre refererer flere steder til CoP, ikke til H's nummerering. Følgende er indholdet af svarene, ikke en påstand om uændret gyldighed i alle senere udgaver.

| ID / side   | Omfang trykt  | Svarenes indhold                                                                                                                                           |
| ----------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| QA-01 / 1   | Liga, DK      | Bevægelser ud kan samtidig bruges som ind til næste sekvens.                                                                                               |
| QA-02 / 1   | Liga, DK      | Ind/ud kan bruge bevægelser hvor tyngdepunkt flyttes, men ikke A1-sværheder.                                                                               |
| QA-03 / 1   | Liga, DK, REG | RS-grupper må starte forskelligt og bevæge sig forskellige afstande. Retning/plane markeret inde i RS mister sit eget bidrag, ikke RS.                     |
| QA-04 / 1   | Liga, DK, REG | Forskellige bevægelser kan være løb, glid, chassé, hop/spring/hink. Små forbindelsesskridt tæller ikke selv; variationerne skal være tydeligt forskellige. |
| QA-05 / 2   | Liga, DK, REG | Retninger/planes kan indgå i ind/ud, når begge regelsæt opfyldes. Dette giver ikke REG ret til et ind/ud-tillæg, som H udelukker.                          |

## Senere validering

Knyt hvert svar til det berørte krav frem for at aktivere hele PDF'en globalt. Test genbrug af ud/ind, D inde i RS, forkert fælles front og legitimt redskabsforsøg uden gyldig D. Delte E/D-årsager skal holdes adskilt.
